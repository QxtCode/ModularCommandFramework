# 快速上手 — 写第一个模块

一个模块就是一个 C++ 类：名字 + 函数。

## 跨平台

test_shell 支持 **Windows、Linux、macOS**。同一份模块代码在所有平台上编译：

| 平台 | 插件扩展名 | 构建命令 |
|------|:---------:|----------|
| Windows  | `.dll` | `cmake --preset debug` |
| Linux    | `.so`  | `cmake --preset debug` |
| macOS    | `.dylib` | `cmake --preset debug` |

所有平台差异由 `core/platform/` 处理——你只需写一次模块逻辑。

## 最小模块（3 件事）

```cpp
#pragma once
#include "sdk/sdk.h"                 // 一个 include 到位（含 ModuleBase）

class MyModule : public ModuleBase {
public:
    // 1. 名字 — -m: 后面跟的名字
    const char* GetName() const override { return "MyModule"; }

    // 2. 注册函数
    bool OnInit() override {
        REGISTER_FUNC("hello", "打招呼", {
            SetResult(pack, "Hello!");   // 成功收尾
        });
        return true;
    }
    // 3. 没了
};
```

### 内置模块：ShellApp::SetupModules 加两行

内置模块在 `core/ShellApp.h` 的 `SetupModules()` 里注册（不在 main.cpp）：

```cpp
#include "modules/MyModule.h"
mgr.AddModule(std::make_unique<MyModule>());
```

### 插件：一行宏，扔进 plugins/

```cpp
// MyModule.cpp
#include "MyModule.h"      // 内含 sdk/sdk.h（含 EXPORT_MODULE）
EXPORT_MODULE(MyModule)
```

编译为共享库（`.dll` / `.so` / `.dylib`），放入 `plugins/`。启动时框架自动加载。`EXPORT_MODULE` 宏定义在 `sdk/Export.h`（自带导出宏，零 core 依赖），全平台通用。

> 模块只需链接 `test_shell_sdk`（纯头文件），**不需要链接 eventbus**。SDK 原理见 [14-SDK原理](14-SDK原理.md)。

## 构建

```bash
# 配置
cmake --preset debug

# 编译
cmake --build --preset debug

# 运行
./out/build/debug/test_shell     # Linux/macOS
out\build\debug\test_shell.exe    # Windows
```

> **Windows 用户**：也可以直接双击 `rebuild_all.bat`。

## 运行

```
> -m:MyModule -f:hello
[OK] Hello!
```

## 接口永远是这三样

```cpp
class IModule {
    virtual const char* GetName() const = 0;   // 必须
    virtual bool        OnInit()         = 0;   // 必须：放 REGISTER_FUNC
    virtual void        OnShutdown()     {}     // 可选：清理资源
    virtual int         GetVersion() const { return 1; }  // 可选
};
```

从最简单的模块到 MetricsCollector，都是这同一个接口。
