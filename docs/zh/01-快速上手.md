# 快速上手 — 写第一个模块

一个模块就是一个 C++ 类：名字 + 函数。

## 跨平台

test_shell 支持 **Windows、Linux、macOS**。同一份模块代码在所有平台上编译：

| 平台 | 插件扩展名 | 构建命令 |
|------|:---------:|----------|
| Windows  | `.dll` | `cmake --preset debug` |
| Linux    | `.so`  | `cmake --preset debug` |
| macOS    | `.dylib` | `cmake --preset debug` |

所有平台差异由 `core/platform/` 处理——你只需写一次模块逻辑。

## 最小模块（3 件事）

```cpp
#pragma once
#include "core/ModuleBaseObject.h"

class MyModule : public ModuleBaseObject {
public:
    // 1. 名字 — -m: 后面跟的名字
    const char* GetName() const override { return "MyModule"; }

    // 2. 注册函数
    bool OnInit() override {
        REGISTER_FUNC("hello", "打招呼", {
            pack->return_value = "Hello!";
            pack->success = true;
        });
        return true;
    }
    // 3. 没了
};
```

### 内置模块：main.cpp 加两行

```cpp
#include "modules/MyModule.h"
mgr.AddModule(std::make_unique<MyModule>());
```

### 插件：一行宏，扔进 plugins/

```cpp
// MyModule.cpp
#include "MyModule.h"
#include "core/ModuleLifeManager.h"
EXPORT_MODULE(MyModule)
```

编译为共享库（`.dll` / `.so` / `.dylib`），放入 `plugins/`。启动时框架自动加载。`EXPORT_MODULE` 宏使用 `PLATFORM_EXPORT`（平台层提供），全平台通用。

## 构建

```bash
# 配置
cmake --preset debug

# 编译
cmake --build --preset debug

# 运行
./out/build/debug/test_shell     # Linux/macOS
out\build\debug\test_shell.exe    # Windows
```

> **Windows 用户**：也可以直接双击 `rebuild_all.bat`。

## 运行

```
> -m:MyModule -f:hello
[OK] Hello!
```

## 接口永远是这三样

```cpp
class IModule {
    virtual const char* GetName() const = 0;   // 必须
    virtual bool        OnInit()         = 0;   // 必须：放 REGISTER_FUNC
    virtual void        OnShutdown()     {}     // 可选：清理资源
    virtual int         GetVersion() const { return 1; }  // 可选
};
```

从最简单的模块到 MetricsCollector，都是这同一个接口。
