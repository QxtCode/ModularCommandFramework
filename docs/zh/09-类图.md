## 关系图例

```
  实线 →  = 拥有/组合 (unique_ptr, 成员变量)
  虚线 →  = 使用/依赖 (单例, 引用)
  △       = 继承
```

## 核心依赖关系

| 从 | 到 | 关系 |
|------|----|------|
| `ShellEngine` | `ThreadPool` | 拥有 |
| `ShellEngine` | `TasksPool` | 拥有 |
| `ShellEngine` | `ResultStore` | 使用 (单例) |
| `TasksPool` | `Task` | 拥有 (池) |
| `Task` | `ParmarPack` | 拥有 (分片) |
| `Task::Step()` | `EventBus` | 使用 (单例) |
| `EventBus` | `Signal<Args>` | 拥有 |
| `Signal<Args>` | `Slot<Args>` | 拥有 |
| `Slot<Args>` | `WeakRefHolder` | 拥有 |
| `Slot<Args>` | `IModule` | 指向 (via weak_ptr) |
| `ModuleLifeManager` | `ModuleBaseObject` | 拥有 (shared_ptr map) |
| `ModuleLifeManager` | `EventBus` | 使用 (单例) |
| `ModuleBaseObject` | `IModule` | 继承 |
| `ModuleBaseObject` | `EventBus` | 使用 (ConnectToEventBus) |
| `MetricsCollector` | `ModuleBaseObject` | 继承 |
| `IModule::Execute()` | `ParmarPack` | 接收指针 |
| `ShellEngine::ProcessInput()` | `CommandParser` | 使用 (单例) |
| `Worker lambda` | `ResultStore` | 使用 (单例, PushResult) |

## 一条命令的完整旅程

```
输入: "-m:Calc -f:add -v:a|1,b|2"
  │
  │  ShellEngine::ProcessInput()
  ├─→ CommandParser.SendCommand("TXT", line)
  │     → 解析为 ParmarPack {mod_id="Calc", func_id="add", params={a:[1],b:[2]}}
  │
  ├─→ TasksPool.Acquire(pack)
  │     → Task, shards_[0] = pack
  │
  ├─→ ThreadPool.Enqueue(lambda)
  │     │
  │     │  [工人线程]
  │     ├─→ Task::Step(EventBus)
  │     │     → bus.Emit("Calc.add", pack)
  │     │       → Signal::TraverseSlots
  │     │         → Slot::Run
  │     │           → WeakRefHolder::Lock() ← v2.4 安全检查
  │     │           → ModuleBaseObject::Execute(pack)
  │     │             → funcs_["add"](pack)  ← 模块的回调
  │     │               → pack->return_value = "3"
  │     │               → pack->success = true
  │     │
  │     ├─→ bus.Emit("task.result", ...)  ← 实时订阅者
  │     │
  │     ├─→ ResultStore::PushResult(id, pack_copy)  ← 落入仓库
  │     │
  │     └─→ tasks.Release(task)  ← 槽位立即归还池子
  │
  │  [主循环, 下一轮]
  ├─→ DrainResults()
  │     → ResultStore::Drain() → ResultItem 批量
  │     → ConsoleFormatter::Format(pack) → "[OK] 3"
  │     → LOG_PLAIN("[OK] 3")
  │
  └─→ WaitForWork()
        → cv.wait_for(HasResults || input || !running)
```
