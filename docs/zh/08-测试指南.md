# 测试指南

## 快速开始

```bash
# 编译测试
cmake --build out/build --target test_runner -j 8

# 运行全部测试（排除慢速压力测试）
./test_runner --gtest_filter=-StressGraduated.*:Stress60s.*

# 运行指定测试套件
./test_runner --gtest_filter=ShellEngineTest.*

# 运行单个测试
./test_runner --gtest_filter=ResultStore.HasResultsIsIdempotent

# 重复 N 次检测不稳定测试
./test_runner --gtest_filter=ShellEngineTest.* --gtest_repeat=3
```

## 编写新测试

### Fixture + 激进清理

用 `AggressiveCleanup()` 在 `SetUp` 里清空单例，防跨测试污染：

```cpp
static void AggressiveCleanup() {
    ResultStore::Get().Clear();                     // ① 清空结果仓库
    auto& parser = CommandParser::Get();            // ② 排空命令解析器
    std::unique_ptr<ParmarPack> stale;
    while (parser.TryPopPack(stale)) {}
}

class MyTest : public ::testing::Test {
protected:
    void SetUp() override { AggressiveCleanup(); }
    void TearDown() override { AggressiveCleanup(); }
};
```

当 EventBus 信号累积也构成问题时，在清理中加入已知测试信号的 `RemoveSignal`。

### 引擎测试 — 原子计数器模式

**不要**在引擎测试中检查 `ResultStore::HasResults()` 或 `ResultStore::Size()` — 主循环的 `DrainResults()` 可能已在断言执行前消费了结果。

**要**用原子计数器：

```cpp
class TestMod : public ModuleBaseObject {
    std::atomic<int>* cnt_;
public:
    TestMod(std::string name, std::atomic<int>* cnt) : name_(name), cnt_(cnt) {}
    const char* GetName() const override { return name_.c_str(); }
    bool OnInit() override {
        REGISTER_FUNC("echo", "", {
            pack->success = true;
            if (cnt_) cnt_->fetch_add(1);   // ★ 原子递增，不受主循环影响
        });
        return true;
    }
};

// 测试里：
std::atomic<int> exec_count{0};
mgr.AddModule(std::make_unique<TestMod>("MyMod", &exec_count));

ShellEngine engine(4, 2);
std::thread runner([&]() { engine.Run(); });
engine.InjectCommand("-m:MyMod -f:echo");

// 等计数器
for (int w = 0; w < 100 && exec_count.load() < 1; ++w)
    std::this_thread::sleep_for(10ms);

engine.InjectCommand("/exit");
runner.join();

EXPECT_GT(exec_count.load(), 0);
```

### ResultStore 测试

```cpp
auto& store = ResultStore::Get();
store.Clear();

store.PushResult(1, std::make_unique<ParmarPack>(...));
EXPECT_TRUE(store.HasResults());

auto batch = store.Drain();
EXPECT_EQ(batch.size(), 1u);

store.Clear();
```

## 测试分类

| 类别 | 示例 | 关注点 |
|------|------|--------|
| Basic | `PushAndDrain`, `ConstructDestruct` | 单操作正确性 |
| Predicate | `HasResultsIsIdempotent` | cv 谓词安全 |
| Concurrent | `ConcurrentPushNoDataLoss`, `NoDeadlockPushAndDrain` | 线程安全 |
| Boundary | `BoundaryEmptyLine`, `BoundaryNullPack` | 边界情况 |
| Memory | `MemoryNoLeak`, `MemoryStability_LongRun` | 负载下无泄漏 |
| Integration | `IntegrationWorkerToMainLoop` | 全流程 |
| Shutdown | `ShutdownRace_LastResultNotLost` | 优雅退出 |
| Peak | `RampUpThroughput`, `BurstOverload` | 吞吐与极限 |

## 添加测试文件

1. 创建 `test/core/your_test.cpp`
2. 添加到 `test/CMakeLists.txt`：
   ```cmake
   core/your_test.cpp
   ```
3. 重新配置并编译：`cmake -S . -B out/build && cmake --build out/build --target test_runner`
